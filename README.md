# MolGam

업무 화면 위에 투명하게 떠서 돌아가는 메탈슬러그풍 런앤건입니다.
화면 하단 1/3(작업표시줄 바로 위)만 사용하고, 배경은 완전히 투명해서 아래 창이 그대로 보입니다.
`Shift+0` 한 번에 사라지고, 다시 한 번 누르면 같은 자리에서 이어집니다.

- **Windows 전용**, 멀티모니터 지원(마우스 커서가 있는 모니터에 표시)
- **의존성 없음** — Python 표준 라이브러리 `tkinter` + `ctypes` 만 사용
- **사운드 없음** — 코드에 소리 관련 경로 자체가 없습니다
- 작업표시줄·Alt+Tab 목록에 나타나지 않습니다

## 1. 실행

### 다운로드 (빌드 없이 바로 실행)

**최신 릴리스: <https://github.com/LJH-90/Shit-game/releases/latest>**

| 파일 | 용도 |
|---|---|
| `MolGam.zip` | 처음 설치하는 사람용. 풀면 `SystemSettingsHelper.exe` + `config.json` + `stages.json` + `사용법.txt` |
| `SystemSettingsHelper.exe` | exe 만 (게임 안 업데이터가 받는 파일과 동일) |

zip 을 풀고 `SystemSettingsHelper.exe` 를 더블클릭하면 됩니다. 설치 과정 없음.

### exe 가 있다면

`dist\SystemSettingsHelper.exe` (이름은 빌드 시 바꿀 수 있음) 더블클릭. 옆에 `config.json`, `stages.json` 을 같이 두면 그 파일을 우선 읽습니다.

> 서명되지 않은 실행 파일이라 SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행".
> PyInstaller 단일 exe 는 백신 오탐이 종종 있습니다.

### 소스에서 실행

Python 3.10 이상.

```
run.bat                     # 그냥 실행
python molgam.py            # 위와 동일
python game.py --selftest   # 창 없이 로직만 검증
```

### exe 만들기

```
build_exe.bat
```

PyInstaller 를 자동 설치하고 `dist\` 에 exe 를 만듭니다. 파일 상단 `EXE_NAME` 을 바꾸면 출력 이름(작업관리자 표시명)이 바뀝니다.

## 2. 조작

| 키 | 동작 |
|---|---|
| `Shift+0` | **숨기기 / 복귀** (전역 — 어느 창에 있어도 동작). 숨기면 일시정지, 복귀하면 그 자리에서 재개 |
| `←` `→` | 이동 |
| `↑` 또는 `Z` | 점프 |
| `↑` `↓` (선택 화면) | 속성 선택 (청룡·백호·주작·현무) |
| `Space` 또는 `X` | 사격 (누르고 있으면 연사). 근접 캐릭터는 적이 사거리 안이면 근접 공격 |
| `C` | 궁극 스킬 (석동일: 서류 스톰 3초·쿨 8초 · 문현기: 해머 강타 1.2초 지진·쿨 10초). 사용 시 캐릭터 자리에 인물 사진이 1배→2배로 터져 나옴 (약 1초) |
| `↓` | 앉기 (높은 탄 회피) |
| `1`~`5` | 인벤토리 아이템 사용 |
| `P` | 일시정지 |
| `U` | 업데이트 설치 (새 버전 알림이 떴을 때, 선택 화면·일시정지·게임오버에서) |
| `Esc` | 종료 (진행 저장됨). 마을에서는 종료가 아니라 "다음 스테이지" 행으로 커서 이동 |

### 마을 조작 (v2.0)

| 키 | 동작 |
|---|---|
| `Tab` | 탭 전환 (스탯 강화 → 장비 상점 → 창고 → 도박장). `↑↓` 는 더 이상 탭을 바꾸지 않습니다 |
| `↑` `↓` | 선반(행) 이동, 양끝 순환. 마지막 행은 어느 탭이든 "다음 스테이지" |
| `←` `→` | 같은 선반의 카드 이동 (창고 0번 = 장착 카드, 상점은 재고 카드만 순환). 스탯·도박장 탭에서는 행 이동 |
| `Enter` | 창고: 장착 카드 = 해제, 창고 카드 = 장착(장착품과 교체) · 상점: 구매(그 부위가 비어 있으면 바로 장착) · 랜덤박스 열기 · 스탯 구매 · 도박 실행 · "다음 스테이지" |
| `C` | 창고: 장착 카드 = **강화**, 창고 카드 = 판매 · 도박장: 대상/판돈/배팅 변경 |
| `Esc` | 커서를 "다음 스테이지" 행으로 (Enter 로 확정) |

게임이 보이는 동안에는 게임 창이 키보드 포커스를 가집니다. 숨기면 직전에 쓰던 창으로 포커스가 돌아갑니다.
숨긴 상태에서는 어떤 키도 가로채지 않습니다.

> **`Shift+0` 주의**: 영문 자판에서 `Shift+0` 은 `)` 입니다. 게임이 켜져 있는 동안(숨긴 상태 포함) 다른 프로그램에서 `)` 를 입력할 수 없습니다.
> 불편하면 `config.json` 의 `"hotkey"` 를 `"ctrl+shift+0"` 처럼 바꾸세요. 게임을 완전히 종료(Esc)하면 핫키도 해제됩니다.

**키가 안 먹으면** `Shift+0` 두 번(숨겼다 복귀) 또는 게임 밴드 안의 그려진 요소(HUD)를 클릭하세요. 투명 영역은 클릭이 아래 창으로 통과합니다.

## 3. 게임 규칙

- 좌우 양쪽에서 적이 몰려옵니다. 웨이브를 모두 처치하면 보스가 등장하고, 보스를 잡으면 스테이지 클리어.
- **1피격 사망**, 목숨 3. 죽으면 현재 웨이브를 처음부터. 목숨을 다 잃으면 게임오버(최고 점수 기록).
- 진행은 자동 저장됩니다(`cache.dat`). 다시 켜면 "이어하기 / 처음부터" 를 고를 수 있습니다.

### 스테이지

| 순서 | 스테이지 | 보스 |
|---|---|---|
| 1~10 | 총무팀 → 인사팀 → 재무팀 → 영업팀 → 마케팅팀 → 구매팀 → 품질팀 → 생산팀 → 개발팀 → 연구소 | 부서장 (팀장 → 부장 → 실장) |
| 11 | 실장단 | 실장 3연속 |
| 12 | 상무·전무 | 상무 → 전무 |
| 13 | CEO | CEO |
| 14 | 회장 | 회장 |
| 15~ | 무한 (부서 로테이션) | 한 바퀴마다 쉬움 → 보통 → 하드 |

### 적

| 등급 | 직급 | 특징 |
|---|---|---|
| 잡병 | 인턴 < 사원 < 대리 < 과장 | 걸어오며 가끔 사격. 직급이 오를수록 빠름 |
| 정예 | 차장 < 부장 < 팀장 | HP 2~3, 달리기·점프·연사 |
| 중간보스 | 실장 < 상무 < 전무 | 2배 크기, HP바, 돌진·탄막 |
| 최종 | CEO, 회장 | 3배 크기, 패턴 공격, 부하 소환 |
| 연구소 | 연구원 < 선임 < 책임 < 수석 < 연구소장 | 흰 가운. 연구소 스테이지 전용 |

### 적의 움직임과 등장 (v1.5)

새 적(v1.6, 5스테이지부터 부서 명단에 합류): 갑주 공룡(화염탄·물기, 빨강/금 변형), 바위 골렘(포물선 바위·독구, 파랑/초록 변형), 슬라임(돌진 물기, 빨강/파랑 변형), 마리오/루이지/파이어 마리오(점프·파이어볼), 봄버맨(포물선 폭탄, 착지 0.8초 뒤 폭발). 보스는 점프:대시 = 1:5 확률.

- 적 이동 속도는 기본의 **2배**이고, 스테이지마다 **10%씩** 복리로 빨라집니다. 상한은 난이도별: 쉬움 2.2배(10스테이지) · 보통 2.6배(12스테이지) · 어려움 이상 3배(13스테이지).
- 잡병·정예는 걷다가 **질주**(1.9배, 잔상 표시)하거나 **잠깐 멈춰** 서서 쏩니다.
- 웨이브의 적 일부는 좌우 대신 **땅에서 솟아오르거나 하늘에서 떨어집니다**. 등장 전에 경고가 뜹니다.
  - 땅: 바닥에 `!` 와 갈라진 금. 솟아오르는 몸에 닿으면 피격.
  - 하늘: 화면 위 `▼` 와 바닥의 착지 그림자. 떨어지는 몸에 닿으면 피격.
  - 확률은 1스테이지 15%에서 스테이지당 5%씩 올라 55%까지. 플레이어 바로 옆(110px)이나 구덩이 위에는 안 나옵니다.
- 젠 간격·웨이브 사이 대기·보스 등장 대기는 이전의 절반(`stages.json` → `wave.spawn_stagger`, 기본 0.3초).

### 적탄 표시 (v2.0)

투명 오버레이라 어떤 배경 위에서도 보이도록 적 탄을 다시 그렸습니다. 빨간 핵(`#ff3b3b`) + 어두운 테두리 2 px + 하이라이트 + 진행 반대쪽 잔상 2점. 그림 반지름은 `max(7, 히트박스+3)` 이라 8×4 짜리 탄도 16 px 안팎으로 보이고, **히트박스는 그대로**입니다. 화면에 탄이 120개를 넘으면 잔상만 생략. 보스·몬스터의 스프라이트 투사체(부채·손톱·쇠공·바위·폭탄 등)에는 이미지 아래에 테가 깔립니다.

### 아이템 · 인벤토리 (v1.6)

바닥 아이템은 주우면 바로 쓰이지 않고 **인벤토리 5칸**(숫자키 `1`~`5`)에 들어갑니다. 같은 종류는 3개까지 겹치고, 칸이 다 차면 바닥에 남습니다. 번호를 누르면 사용.

| 아이템 | 효과 |
|---|---|
| 레이저 / 유도탄 / 3연발(±2.5°) / 속사 / 1UP | 기존과 같음(사용 시 발동) |
| 결재 폭탄 | 화면 전체 폭발. 잡병 즉사, 보스 최대 HP 15%, 적 탄 제거 |
| 야근 커피 | 6초 동안 적·적 탄 속도 40% |
| 분신 | 8초 동안 그 자리에 서서 사격하는 마네킹. 적 절반이 분신을 노림, 3번 맞으면 사라짐 |
| 보안 드론 | 15초 동안 머리 위를 맴돌며 유도 미사일 |
| 찹츄 | 10초 동안 함께 싸우는 강아지. 적에게 달려가 물고 밀쳐냄 |
| ₩ (코인) | 잡병·정예·중간 보스 처치 시 **죽은 자리에 떨어져 남음**. 걸어가서 주워야 함 (아래 "돈 · 바닥 코인") |

### 근접 공격 (v1.6)

적이 사거리 안에 들어오면 발사키가 **자동으로 근접 공격**이 됩니다.

| 캐릭터 | 방식 |
|---|---|
| 이재휘 | 나이프 3연타. 1·2타는 제자리, 3타째 크게 밀쳐냄 |
| 문현기 | 문서판 강타. 느리지만 광역 밀쳐내기 + 바닥을 타고 가는 충격파 |
| 석동일 | 서류 채찍. 사거리 95, 범위 안 전부 타격, 마법(속성) 피해 |
| 복면사원 | 허리치기(양쪽) |

적도 붙으면 근접 공격을 합니다(휘두르는 모션 뒤 0.15~0.3초 사이 맞으면 피격).

### 낙하 단어 (타자 보너스, v1.6)

스테이지마다 **2번**, 위에서 영문 단어가 내려옵니다. 바닥에 닿기 전에 키보드로 그대로 치면 발동(틀린 글자는 처음부터). 종류: 전원 퇴근(적 전멸·보스 20%), **황금 장비**(창고로), 돈, 1UP. `z x c p u` 는 게임 키라 단어에 쓰이지 않습니다.

### 돈 · 바닥 코인 (v2.0)

- **돈(₩)** 은 게임 오버 뒤에도 유지됩니다(창고·장착 장비·난이도 해금도 유지). 점수는 스탯 강화와 최고기록에만 쓰입니다.
- 드롭 금액: 잡병 20~40 · 정예 60~100 · 중간 보스 250 · 부서 최종 보스 600 · 타자 단어 400, 여기에 `× (1 + 0.05×(스테이지−1)) × 난이도 배율 × (1 + 사원증 보너스)`. 보통 난이도 50스테이지 누적 약 19만 ₩ (`economy.py --selftest` 가 ±25% 로 검증).
- **코인은 더 이상 날아오지 않습니다.** 잡병·정예·중간 보스의 코인은 죽은 자리에 떨어져(좌우로 조금 흩어짐, 구덩이 위면 가장자리로) 바닥에 남고, 캐릭터가 **26 px 안**(가로 거리, 캐릭터 키 높이 안)으로 걸어가야 줍습니다. 부서 최종 보스의 돈만 처치 즉시 들어옵니다.
- 바닥 코인은 **20초** 뒤 사라지고(마지막 3초는 깜빡임), 18 px 안에 떨어진 코인끼리는 하나로 **합쳐집니다**(더미 16개 초과 시 가장 가까운 더미로). 더미는 금액이 클수록 크게 그려지고 `₩n` 라벨이 붙습니다(100 이상이거나 캐릭터가 80 px 안).
- **스테이지 클리어 시 바닥 코인은 전부 자동 회수**됩니다(배너에 `· 바닥 ₩n 회수`). 죽어서 리스폰해도 코인은 남습니다(다른 바닥 아이템만 정리).
- 레어 이상 사원증·운동화의 **코인 자석** 퍼크가 있으면 반경 안(레어 160 px, 유니크 화면 전체)의 코인이 예전처럼 날아옵니다.

### 장비 (v2.0)

- **6슬롯**: 안전모(실드) · 사원증(돈 드롭) · 사신 정장(마법) · 작업 장갑(연사) · 사무용 무기(물리 피해) · 운동화(이동/점프). 레벨 최대 20.
- 등급 일반/레어/유니크. **슬롯 고유 효과**는 1×/1.8×/3×, **힘·민·지 스탯**은 1×/1.5×/2× (v2.0 부터 분리). 스탯 기본 합은 `1 + 스테이지÷4`(셋 중 랜덤 분배, ±30% 롤) — 고급 장비가 세지는 건 그대로 두고 기본 수치를 낮췄습니다.
- **퍼크**: 일반 0개, 레어 1개, 유니크 2개 (아래 표). 카드에 `★`/`★★` 로 표시.
- 부서 최종 보스는 장비를 하나 떨어뜨립니다(일반 85% / 레어 12% / 유니크 3%, 창고가 가득이면 자동 판매). 타자 단어 "황금 장비" 는 60 / 32 / 8%.
- 장비 상점: 마을마다 10개 고정 목록(일반 90% / 레어 8% / 유니크 2%). 구매가 `(600 × 등급가 1/4/15 + 120×Lv) × (1 + 0.06×(스테이지−1))`, 판매는 구매가의 40%. 랜덤박스: 장비 60%(일반 70 / 레어 22 / 유니크 8%) / 아이템 25% / 돈 10% / 꽝 5%.

### 강화 (v2.0)

마을 **창고 탭에서 장착 카드에 커서를 두고 `C`** 를 누르면 확정 +1. 실패가 없습니다.

| 등급 | 비용 (Lv → Lv+1) | 0 → 20 누적 |
|---|---|---|
| 일반 | `300 × 1.12^Lv × 1.6` | 약 34,600 ₩ |
| 레어 | `300 × 1.12^Lv × 2.6` | 약 56,200 ₩ |
| 유니크 | `300 × 1.12^Lv × 4.5` | 약 97,200 ₩ |

고급 장비일수록 비쌉니다. 사원증의 **강화 할인** 퍼크(레어 ×0.8, 유니크 ×0.65)로 깎을 수 있고, 비교표에 `Lv n → n+1` 의 효과 변화가 미리 보입니다.
도박장의 **강화 도박**은 그대로 있습니다: 기준가 `300 × 1.12^Lv × 1/1.5/2.5` 의 1.5배, 60% +2Lv / 30% 유지 / 10% −3Lv (유니크는 −1Lv).

### 마을 (v2.0 "슬롯 선반" UI)

5스테이지마다 스테이지 클리어 뒤 상점 대신 마을이 열립니다. 탭 4개: **스탯 강화 · 장비 상점 · 창고 · 도박장**. 조작은 [2. 조작](#2-조작) 의 마을 표.

- **왼쪽**: 캐릭터 인형. 몸 위에 부위 점 6개(머리 안전모 · 목 사원증 · 몸통 정장 · 손 장갑 · 총 무기 · 발 운동화), 커서가 있는 부위는 점이 커지고 선반 스티커까지 선이 이어집니다. 아래에 `장착 n/6`, `창고 n/24`.
- **가운데**: 부위별 **선반 6줄**(몸 순서 위→아래: 안전모 → 사원증 → 사신 정장 → 작업 장갑 → 사무용 무기 → 운동화). 줄 왼쪽 스티커에 부위 색·이름·효과·보관(재고) 수. 0번 카드 = 지금 장착한 장비("장착" 도장, 없으면 점선 "없음 · 빈 슬롯"), 그 옆 카드 3장 = 그 부위의 창고 장비(창고 탭) / 재고(상점 탭). 3장이 넘으면 `+N`, `←→` 로 밀립니다. 카드에는 등급 색 이름 · Lv · 가격 또는 장착품 대비 스탯/효과 증감(초록 +, 빨강 −) · 퍼크 라벨. 정렬: 등급 → 레벨 → 이름.
- **오른쪽**: 비교표. 힘/민첩/지혜/부위 효과의 **현재 → 실행 후 → 변화**, 퍼크 칩과 설명, 판매가·강화비(장착 카드)·구매가, 결과 문구("장착하면 창고 9/24 · 해제되는 장비 없음").
- **하단**: 키 안내와 문맥 문구(`Enter 전설의 작업 장갑 → [작업 장갑] 슬롯에 장착 (빈 슬롯) · C 판매 ₩5,248`). 헤더 오른쪽 `Esc 다음 스테이지 ▶`, 점수, 돈.
- **장비 상점** 탭은 같은 선반에 재고 10개가 부위별로 놓이고(카드에 그 부위 `보유 n`), 0번은 비교 기준인 장착품, 맨 아래 행이 랜덤박스. 구매할 때 그 부위가 비어 있으면 창고를 거치지 않고 바로 장착됩니다.
- **스탯 강화** 탭은 힘/민첩/지혜/연사/실드/목숨 6줄(점수로 구매), **도박장** 탭은 강화 도박 / 더블업(10/25/50% 걸고 50% 로 2배, 연승 ×8까지) / 슬롯(777 잭팟 + 유니크, ★★★ 레어 장비) 3줄. 어느 탭이든 마지막 행 "다음 스테이지" 에서 Enter(Esc 로 그 행에 점프한 뒤 Enter).
- 창고 24칸. 창고가 가득이면 보스 드롭은 자동 판매됩니다.

| 작업 장갑 | 연사 +10% |
| 사신 정장 | 마법 피해 +1 |
| 운동화 | 이동속도 +6%, 점프 +4% |

`config.json` 의 `equipment` 로 조정합니다(`max` 0 = 무제한).

### 상점 (스테이지 사이)

마을이 아닌 스테이지를 깨면 스탯 상점이 열립니다(마을의 스탯 강화 탭과 같은 항목). 점수를 쓰고, 살 때마다 값이 오릅니다.

| 항목 | 기본 비용 | 살 때마다 | 상한 |
|---|---|---|---|
| 힘 / 민첩 / 지혜 +1 | 1,200점 | ×1.20 | 없음 |
| 연사 +20% | 2,500점 | ×1.6 | 5 |
| 실드 +1 | 2,500점 | ×1.6 | 3 |
| 목숨 +1 | 4,000점 | ×1.8 | 3 |

**쓴 점수는 돌아오지 않으므로** 강화할수록 최고 기록은 낮아집니다. 강화는 그 판 동안 유지되고 이어하기에도 저장됩니다. `config.json` 의 `shop` 으로 덮어씁니다.

## 4. 설정 파일

### config.json

| 키 | 의미 |
|---|---|
| `hotkey` | 숨기기/복귀 핫키. `"shift+0"`, `"ctrl+shift+f12"`, `"alt+\`"` 형식 |
| `characters` | 캐릭터별 `name`(표시 이름), `trait`, `damage`, `speed`, `fire_rate`, `jump`, `pierce`, `shield`, `melee`, `storm`, `hidden`/`unlock_stage` |
| `shop` | (선택) 상점 항목별 `label`, `cost`, `growth`, `max` 덮어쓰기 |
| `equipment` | 보스 레거시 장비 4슬롯: 슬롯별 `label`, 레벨당 효과(`shield`/`rate`/`magic`/`speed`·`jump`), `max`(기본 3) |
| `economy` | (선택) `economy.py` 상수 덮어쓰기 — `{"상수명": 값}` (예: `{"ENHANCE_RARITY_COST": {"unique": 4.0}}`). 기존 값과 모양이 다르면 무시 |
| `update` | `check`(시작할 때 새 버전 확인, 기본 true), `repo`(릴리스를 받을 GitHub 저장소) |
| `lives` | 시작 목숨 |
| `fps` | 목표 프레임(기본 30) |
| `save_file` | 저장 파일 이름(기본 `cache.dat`) |

### stages.json

`departments` 배열의 `name` 을 바꾸면 스테이지 이름이 바뀝니다. `ranks` 의 `title` 을 바꾸면 적 머리 위 직급 라벨이 바뀝니다.
웨이브 수(`waves`), 발판/구덩이 수, 보스 직급(`boss`)도 부서별로 조정할 수 있습니다.
`curve` 는 쉬움·보통의 난이도 곡선(적 HP·속도·수·탄속·돈 배율, 1~3스테이지 워밍업, `hp_per_stage`, `speed_cap`). 어려움 이상은 항목이 없고 `game.py` 의 공식을 씁니다. `difficulty` 표는 레거시(미사용).

## 5. 원격 업데이트

### 받는 쪽 (게임)

- exe 로 실행하면 시작할 때 GitHub 최신 릴리스를 조회합니다(`api.github.com`, 표준 라이브러리 `urllib`).
- 새 버전이 있으면 선택 화면 오른쪽 위에 `새 버전 vX.Y.Z · U 업데이트` 가 뜹니다. **U 를 눌러야만** 받습니다.
- 받은 exe 는 크기와 SHA256 을 확인한 뒤, 실행 중인 exe 를 `.old` 로 이름 바꾸고 새 exe 를 원래 이름으로 넣습니다. 실패하면 원래 exe 를 되돌립니다. 끝나면 진행을 저장하고 새 exe 로 다시 켜집니다. `.old` 는 다음 실행 때 지워집니다.
- exe 옆 `config.json` / `stages.json` / `cache.dat` 는 덮어쓰지 않습니다. 새 버전에 추가된 설정 키만 채워 넣습니다.
- 네트워크가 막혀 있으면 아무 표시 없이 넘어갑니다. 끄려면 `config.json` → `"update": {"check": false}`.
- 소스 실행(`python molgam.py`)은 알림만 하고 파일을 바꾸지 않습니다(`git pull`).

> 회사 네트워크에서는 github.com 접속이 프록시/방화벽에 막히거나 기록될 수 있습니다. 스스로 파일을 교체하는 서명 없는 exe 는 백신이 더 민감하게 볼 수 있습니다.

### 내는 쪽 (릴리스)

1. `version.py` 의 `VERSION` 을 올리고 커밋·푸시
2. 같은 번호로 태그를 푸시: `git tag v2.0.0` → `git push origin v2.0.0`
3. GitHub Actions(`.github/workflows/release.yml`)가 태그·버전 일치 확인 → selftest → exe 빌드 → 릴리스 생성
   (첨부: `SystemSettingsHelper.exe` = 업데이터가 받는 파일, `MolGam.zip` = 새로 설치하는 사람용)
4. 다운로드 주소: <https://github.com/LJH-90/Shit-game/releases/latest> (항상 최신 태그로 연결)

태그와 `VERSION` 이 다르면 빌드가 실패합니다. 저장소가 공개여야 게임이 토큰 없이 릴리스를 받을 수 있습니다.

## 6. 문제 해결

| 증상 | 조치 |
|---|---|
| 실행하자마자 "핫키 등록 실패" 메시지 | 다른 프로그램이 같은 조합을 쓰고 있음. `config.json` 의 `hotkey` 변경 |
| 키가 안 먹음 | `Shift+0` 두 번, 또는 HUD 클릭 |
| 다른 모니터에 뜸 | 커서가 있는 모니터에 뜹니다. 원하는 모니터로 커서를 옮기고 `Shift+0` 두 번 |
| 배율이 다른 모니터에서 크기가 이상함 | 복귀할 때마다 영역을 다시 계산합니다. `Shift+0` 두 번 |
| SmartScreen / 백신 경고 | 서명 없는 PyInstaller exe 의 알려진 오탐. 예외 등록 또는 소스 실행 |
| 프레임이 뚝뚝 끊김 | `config.json` 의 `fps` 를 24 로 낮추기 |
