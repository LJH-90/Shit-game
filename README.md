# MolGam

업무 화면 위에 투명하게 떠서 돌아가는 메탈슬러그풍 런앤건입니다.
화면 하단 1/3(작업표시줄 바로 위)만 사용하고, 배경은 완전히 투명해서 아래 창이 그대로 보입니다.
`Shift+0` 한 번에 사라지고, 다시 한 번 누르면 같은 자리에서 이어집니다.

- **Windows 전용**, 멀티모니터 지원(마우스 커서가 있는 모니터에 표시)
- **의존성 없음** — Python 표준 라이브러리 `tkinter` + `ctypes` 만 사용
- **사운드 없음** — 코드에 소리 관련 경로 자체가 없습니다
- 작업표시줄·Alt+Tab 목록에 나타나지 않습니다

---

## 1. 실행

### exe 가 있다면

`dist\SystemSettingsHelper.exe` (이름은 빌드 시 바꿀 수 있음) 더블클릭. 옆에 `config.json`, `stages.json` 을 같이 두면 그 파일을 우선 읽습니다.

> 서명되지 않은 실행 파일이라 SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행".
> PyInstaller 단일 exe 는 백신 오탐이 종종 있습니다.

### 소스에서 실행

Python 3.10 이상.

```
run.bat                     # 그냥 실행
python molgam.py            # 위와 동일
python game.py --selftest   # 창 없이 로직만 검증
```

### exe 만들기

```
build_exe.bat
```

PyInstaller 를 자동 설치하고 `dist\` 에 exe 를 만듭니다. 파일 상단 `EXE_NAME` 을 바꾸면 출력 이름(작업관리자 표시명)이 바뀝니다.

## 2. 조작

| 키 | 동작 |
|---|---|
| `Shift+0` | **숨기기 / 복귀** (전역 — 어느 창에 있어도 동작). 숨기면 일시정지, 복귀하면 그 자리에서 재개 |
| `←` `→` | 이동 |
| `↑` 또는 `Z` | 점프 |
| `Space` 또는 `X` | 사격 (누르고 있으면 연사) |
| `↓` | 앉기 (높은 탄 회피) |
| `P` | 일시정지 |
| `Esc` | 종료 (진행 저장됨) |

게임이 보이는 동안에는 게임 창이 키보드 포커스를 가집니다. 숨기면 직전에 쓰던 창으로 포커스가 돌아갑니다.
숨긴 상태에서는 어떤 키도 가로채지 않습니다.

> **`Shift+0` 주의**: 영문 자판에서 `Shift+0` 은 `)` 입니다. 게임이 켜져 있는 동안(숨긴 상태 포함) 다른 프로그램에서 `)` 를 입력할 수 없습니다.
> 불편하면 `config.json` 의 `"hotkey"` 를 `"ctrl+shift+0"` 처럼 바꾸세요. 게임을 완전히 종료(Esc)하면 핫키도 해제됩니다.

**키가 안 먹으면** `Shift+0` 두 번(숨겼다 복귀) 또는 게임 밴드 안의 그려진 요소(HUD)를 클릭하세요. 투명 영역은 클릭이 아래 창으로 통과합니다.

## 3. 게임 규칙

- 좌우 양쪽에서 적이 몰려옵니다. 웨이브를 모두 처치하면 보스가 등장하고, 보스를 잡으면 스테이지 클리어.
- **1피격 사망**, 목숨 3. 죽으면 현재 웨이브를 처음부터. 목숨을 다 잃으면 게임오버(최고 점수 기록).
- 진행은 자동 저장됩니다(`cache.dat`). 다시 켜면 "이어하기 / 처음부터" 를 고를 수 있습니다.

### 스테이지

| 순서 | 스테이지 | 보스 |
|---|---|---|
| 1~10 | 총무팀 → 인사팀 → 재무팀 → 영업팀 → 마케팅팀 → 구매팀 → 품질팀 → 생산팀 → 개발팀 → 연구소 | 부서장 (팀장 → 부장 → 실장) |
| 11 | 실장단 | 실장 3연속 |
| 12 | 상무·전무 | 상무 → 전무 |
| 13 | CEO | CEO |
| 14 | 회장 | 회장 |
| 15~ | 무한 (부서 로테이션) | 한 바퀴마다 쉬움 → 보통 → 하드 |

### 적

| 등급 | 직급 | 특징 |
|---|---|---|
| 잡병 | 인턴 < 사원 < 대리 < 과장 | 걸어오며 가끔 사격. 직급이 오를수록 빠름 |
| 정예 | 차장 < 부장 < 팀장 | HP 2~3, 달리기·점프·연사 |
| 중간보스 | 실장 < 상무 < 전무 | 2배 크기, HP바, 돌진·탄막 |
| 최종 | CEO, 회장 | 3배 크기, 패턴 공격, 부하 소환 |
| 연구소 | 연구원 < 선임 < 책임 < 수석 < 연구소장 | 흰 가운. 연구소 스테이지 전용 |

### 아이템

적을 처치하면 가끔 떨어집니다(잡병 10%, 정예 30%, 보스는 항상). 9초 뒤 사라지고, 죽으면 무기를 잃습니다.

| 표시 | 아이템 | 효과 |
|---|---|---|
| `L` | 레이저 | 화면 끝까지 관통하는 빔, 데미지 +1. 10초 |
| `H` | 유도탄 | 가장 가까운 적을 따라가는 미사일 25발, 데미지 +2 |
| `S` | 3연발 | 위·정면·아래 3방향 동시 발사. 12초 |
| `R` | 속사 | 연사 2배. 12초 |
| `♥` | 1UP | 목숨 +1 (최대 5) |

### 난이도

스테이지가 오를수록 같은 직급도 체력이 늘어 한 방에 죽지 않습니다(`stages.json` → `progression.hp_per_stage`, 기본 0.35: 3스테이지 ×1.7, 6스테이지 ×2.75). 보스도 스테이지당 8%씩 늘어납니다.

### 캐릭터

| 캐릭터 | 특성 | 효과 |
|---|---|---|
| 이재휘 | 힘 | 탄 데미지 2배, 이동속도 0.9배 |
| 문현기 | 지능 | 관통탄, 적 HP 표시 |
| 석동일 | 민첩 | 이동 1.3배, 점프 높음, 연사 1.5배 |

## 4. 설정 파일

### config.json

| 키 | 의미 |
|---|---|
| `hotkey` | 숨기기/복귀 핫키. `"shift+0"`, `"ctrl+shift+f12"`, `"alt+\`"` 형식 |
| `characters` | 캐릭터별 `name`(표시 이름), `trait`, `damage`, `speed`, `fire_rate`, `jump`, `pierce` |
| `lives` | 시작 목숨 |
| `fps` | 목표 프레임(기본 30) |
| `save_file` | 저장 파일 이름(기본 `cache.dat`) |

### stages.json

`departments` 배열의 `name` 을 바꾸면 스테이지 이름이 바뀝니다. `ranks` 의 `title` 을 바꾸면 적 머리 위 직급 라벨이 바뀝니다.
웨이브 수(`waves`), 발판/구덩이 수, 보스 직급(`boss`)도 부서별로 조정할 수 있습니다.

## 5. 문제 해결

| 증상 | 조치 |
|---|---|
| 실행하자마자 "핫키 등록 실패" 메시지 | 다른 프로그램이 같은 조합을 쓰고 있음. `config.json` 의 `hotkey` 변경 |
| 키가 안 먹음 | `Shift+0` 두 번, 또는 HUD 클릭 |
| 다른 모니터에 뜸 | 커서가 있는 모니터에 뜹니다. 원하는 모니터로 커서를 옮기고 `Shift+0` 두 번 |
| 배율이 다른 모니터에서 크기가 이상함 | 복귀할 때마다 영역을 다시 계산합니다. `Shift+0` 두 번 |
| SmartScreen / 백신 경고 | 서명 없는 PyInstaller exe 의 알려진 오탐. 예외 등록 또는 소스 실행 |
| 프레임이 뚝뚝 끊김 | `config.json` 의 `fps` 를 24 로 낮추기 |

## 6. 구조

| 파일 | 역할 |
|---|---|
| `molgam.py` | 진입점. 창·스프라이트·로직을 묶고 Canvas 에 그림 |
| `overlay.py` | 투명 오버레이 창, 모니터 판정, 전역 핫키, 포커스 반환, 작업표시줄 숨김 |
| `game.py` | 게임 로직(엔티티·물리·웨이브·스테이지·보스·점수·저장). tk 의존 없음, `--selftest` |
| `sprites.py` | 프레임 데이터 → PhotoImage (팔레트 적용, 반전, 확대, 캐시) |
| `assets_data.py` | 생성물. 시트에서 추출한 프레임(픽셀 클래스/명암) |
| `stages.json` / `config.json` | 스테이지·직급 정의 / 핫키·캐릭터·저장 설정 |
| `tools/` | 개발용. 스프라이트 시트 분할·리컬러 (Pillow 필요, 런타임에는 불필요) |
| `PLAN.md` / `INTERFACES.md` | 설계 계획 / 모듈 간 계약 |
