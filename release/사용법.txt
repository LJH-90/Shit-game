MolGam - 회사 화면 위에 투명하게 뜨는 런앤건

1. 이 폴더 통째로 아무 데나 두고 SystemSettingsHelper.exe 실행
   (SmartScreen 경고가 뜨면 "추가 정보" -> "실행")
2. 화면 하단 1/3에 게임이 뜸. 캐릭터 고르고 Space
3. Shift+0 : 숨기기 / 다시 꺼내기 (어느 창에서든)
   ← →   : 이동      ↑ 또는 Z : 점프
   Space  : 사격      ↓ : 앉기      C : 스킬(석동일 서류 스톰)
   P : 일시정지      Esc : 종료
4. 문현기는 적이 붙으면 사격 대신 근접 공격, 실드 3칸.
   스테이지를 깨면 상점에서 점수로 강화(쓴 점수는 기록에서 빠짐).
   5스테이지를 깨면 숨겨진 캐릭터가 열림.
5. 업데이트: 선택 화면 오른쪽 위에 "새 버전 · U 업데이트" 가 뜨면 U.
   받아서 교체한 뒤 자동으로 다시 켜짐. config.json 과 저장은 그대로.
   업데이트 확인을 끄려면 config.json 의 "update" -> "check" 를 false 로.
6. 핫키 바꾸기: config.json 의 "hotkey" 수정 (예: "ctrl+shift+0")
7. 진행은 옆에 생기는 cache.dat 에 저장됨

소리 없음. 작업표시줄/Alt+Tab 에 안 뜸.
